This work proposes an experimental study to comparatively evaluate alternatives
to MinIO for object storage in hybrid \textit{Data Lake} architectures. MinIO
will be used as the baseline, and RustFS will be included among the evaluated
solutions, together with other alternatives selected through a systematic
mapping study. The analysis will cover performance, S3 API compatibility,
interoperability with AWS, Azure and GCP, resource consumption, costs, licensing,
maturity, governance, sustainability, and technological risks. The systematic
mapping will identify relevant dimensions, metrics, and research gaps to guide
the construction of a standardized experimental environment.

\begin{keywords}
Object storage, Data Lake, MinIO, RustFS, S3 API, hybrid cloud.
\end{keywords}
